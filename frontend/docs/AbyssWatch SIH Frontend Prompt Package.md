# AbyssWatch SIH Frontend Prompt Package

This package contains a copy-ready prompt and supporting specifications for generating a four-to-five-page React frontend prototype for a Smart India Hackathon presentation.

## Recommended use

Paste the complete contents of `01_master_antigravity_prompt.md` into your AI website builder. If the builder supports reference files, also upload the remaining Markdown files so it can preserve the page architecture, visual system, mock data, and interaction behavior.

| File | Purpose |
|---|---|
| `01_master_antigravity_prompt.md` | Main generation prompt. This is the only file required for a first pass. |
| `02_page_architecture_and_demo_flow.md` | Five-route structure, jury walkthrough, success criteria, and seven-day execution mapping. |
| `03_visual_system_and_components.md` | Design direction, colors, typography, accessibility, and reusable component contract. |
| `04_mock_data_and_interaction_contract.md` | TypeScript models, seed values, mock service functions, state transitions, and explanation copy. |

## Product name

**AbyssWatch — Seabed Intelligence & Anomaly Response Platform**

## Suggested SIH problem framing

**Problem:** Marine sonar surveys produce large volumes of difficult-to-review data, making it hard for operators to identify newly emerging seabed anomalies quickly and consistently.

**Proposed solution:** AbyssWatch establishes a seabed baseline, highlights spatial and temporal deviations, explains why a location was flagged, and keeps a human reviewer in the loop so validated feedback can improve subsequent model versions.

**Demo outcome:** Upload a survey, observe simulated processing, inspect the normality map, investigate Anomaly #017, compare it over time, submit a human review decision, and generate a survey intelligence report.
