# Contributing Guidelines

Thank you for your interest in contributing to S.A.G.A.R. Command! We welcome contributions from everyone.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/sagar-version-2.git`
3. Install frontend dependencies: `npm install`
4. Install backend dependencies: `cd backend && npm install`
5. Run the development server: `npm run dev`

## Branch Naming Convention

- `feat/feature-name`
- `fix/bug-name`
- `docs/documentation-change`
- `chore/maintenance-task`

## Pull Request Process

1. Create a new branch from `main`
2. Make your changes and commit them with clear, descriptive commit messages
3. Push your branch to your fork
4. Open a Pull Request against our `main` branch
5. Ensure all checks in the CI pipeline pass (linting and building)
6. A maintainer will review your PR and merge it if approved

## Code of Conduct

Please note that this project is released with a Contributor Code of Conduct. By participating in this project you agree to abide by its terms.
