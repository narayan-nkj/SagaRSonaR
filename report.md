# SagaRSonaR (SonarVision) - Technical Report

## 1. Technology Stack
The application is built using a modern, full-stack architecture optimized for high-performance mapping and ML inference.

**Frontend (Client-side):**
- **Framework:** React 19 with TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (v4) with a custom Glassmorphic design system
- **Mapping Engine:** MapLibre GL JS & `react-map-gl`
- **Data Visualization:** Recharts
- **Icons:** Lucide React

**Backend (Server-side & API):**
- **Framework:** FastAPI (Python 3) & Uvicorn
- **Database:** SQLite with SQLAlchemy (ORM)
- **Data Validation:** Pydantic & Pydantic Settings
- **Computer Vision & Processing:** OpenCV (`opencv-python-headless`), Pillow, Numpy
- **Geospatial Processing:** Shapely, PyProj

---

## 2. ML Models & Datasets Used
- **Detection Model:** Ultralytics YOLOv8 / YOLO11 integrated with ONNX Runtime (`onnx`, `onnxruntime`) for fast CPU/GPU inference. The system also uses PyTorch (`torch`) for deep learning operations.
- **Dataset (GhostVision Simulated Dataset):** 
  - The dataset simulates sonar scans generated by Autonomous Underwater Vehicles (AUVs) and Research Vessels across major Indian and global harbours (e.g., Mumbai Harbor, Chennai Port, Kochi Harbor, Thunder Bay). 
  - The dataset is trained to classify specific underwater hazards such as: *Crab-Pot, Ghost Net, Debris (Metal), Debris (Plastic), and Shipwrecks*.
